# Level 4 - Background Asset Guide

## Spesifikasi Level
- **Tema**: Snow / Ice
- **Ukuran Grid**: 13 x 25 (13 Kolom x 25 Baris)
- **Perspektif**: Top-Down 90 Derajat (Orthographic)
- **Target Audience**: Puzzle adventure anak-anak dan remaja

## Panduan Visual
- **Suasana**: Dingin bersalju (*frosty winter atmosphere*), putih bersih dengan sentuhan biru es beku.
- **Background Layer**: Lapisan salju putih bersih (*bright white snow surface*).
- **Aturan**: Tidak ada karakter, tidak ada musuh, tidak ada UI/teks.
