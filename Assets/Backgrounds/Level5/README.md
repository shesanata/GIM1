# Level 5 - Background Asset Guide

## Spesifikasi Level
- **Tema**: Lava / Volcano
- **Ukuran Grid**: 15 x 29 (15 Kolom x 29 Baris)
- **Perspektif**: Top-Down 90 Derajat (Orthographic)
- **Target Audience**: Puzzle adventure anak-anak dan remaja

## Panduan Visual
- **Suasana**: Gunung berapi aktif dramatis namun tetap ramah visual (*vibrant, child/teen-friendly volcanic aesthetic*).
- **Background Layer**: Bebatuan basal vulkanik gelap (*dark basalt rock surface*).
- **Aturan**: Tidak ada karakter, tidak ada musuh, tidak ada UI/teks.
