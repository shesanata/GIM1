# Level 2 - Background Asset Guide

## Spesifikasi Level
- **Tema**: Ground / Earth
- **Ukuran Grid**: 9 x 17 (9 Kolom x 17 Baris)
- **Perspektif**: Top-Down 90 Derajat (Orthographic)
- **Target Audience**: Puzzle adventure anak-anak dan remaja

## Panduan Visual
- **Suasana**: Tanah alami yang hangat (*warm natural earth colors*), variasi lapisan tanah atau bebatuan berbeda dari Level 1.
- **Background Layer**: Tekstur dasar tanah gembur/padat (*packed dirt / rich soil*).
- **Aturan**: Tidak ada karakter, tidak ada musuh, tidak ada UI/teks.
