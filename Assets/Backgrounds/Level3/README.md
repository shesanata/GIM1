# Level 3 - Background Asset Guide

## Spesifikasi Level
- **Tema**: Grass
- **Ukuran Grid**: 11 x 21 (11 Kolom x 21 Baris)
- **Perspektif**: Top-Down 90 Derajat (Orthographic)
- **Target Audience**: Puzzle adventure anak-anak dan remaja

## Panduan Visual
- **Suasana**: Cerah, segar, hijau subur (*lush green grass theme*), menyenangkan.
- **Background Layer**: Padang rumput rapi dengan tekstur rumput hijau cerah.
- **Aturan**: Tidak ada karakter, tidak ada musuh, tidak ada UI/teks.
